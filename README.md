# TattooDarte
Gestión de citas para un estudio de tatuajes

## Descripcion de la idea
Una aplicación para gestionar citas:
- Tendra un formulario en el que selecciones el dia de la cita
- La hora de inicio y limite horario
- Con esos datos compruebe en la base de datos si la cita esta disponible
- Si esta disponible se guarde el Nombre, el telefono, una breve descripcion y una        imagen

## Stack tecnológico

    - Java  para el backend:
        -Spring Boot con dependencias:
            - Spring Web
            - Spring Data JPA
            - SQL Server Driver
            - Spring Boot DevTools (opcional para desarrollo)

    - SQL Server para la gestión de BBDD 
    - Angular para el front

## Pruebas:
    - Backend:
        - Pruebas unitarias con JUnit.
        - Pruebas de integración con Postman o Swagger.

    - Frontend:
        - Pruebas manuales del flujo de creación de cita.
        - Validación de errores y mensajes al usuario.
